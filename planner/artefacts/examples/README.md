# Setup illustration

`phone-stand-17cm.png` is an AI-generated instructional illustration selected by the maintainer. It shows a synthetic `TEST-CASE-0001` label and is not a calibration template. The 17 cm height illustrates one setup, not a validated distance for every phone. It is included on page 2 of both printable PDFs.

The public release contains no source photographs. Print the original A4 or Letter PDF at actual size to obtain the mat.
